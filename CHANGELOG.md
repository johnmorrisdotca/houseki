# Changelog

## 0.1.0

- Add original Falling Triplets, Colour Chains, Stone Collapse and Gem Swap engines with immutable state, seeded play, validated settings and canonical saves.
- Include 300 graded challenges and three bilingual lessons per game.
- Provide family-style keyboard, keypad and touch demos, configurable boards, stored tools, goal progress and shared animation preferences.
- Add optional Black Hole powers, Shizen magnetic stones and bounded rebound.
- Include an experimental Magnetic Blocks engine with bonded squares, magnetic floor schedules, a Floor Switch and impact drops.
- Publish typed entry points, a generated API reference, MIT license and reproducible package checks.
